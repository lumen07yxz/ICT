- 开发态空目录布局预览保留卡片/表格切换，以检查两种空态；真实项目有数据后恢复 V4.0 的搜索、筛选和视图切换。
- 过滤字段仍以实际 API 和数据为准；缺少数据时不展示或推测质量、类型、更新时间等值。

- 配置了令牌后保留“新建平台任务”原流程；本机任务创建始终独立可用。仅导航到设置页，不自动提交凭据或连接服务。

## 2026-11-06 论文复现任务列表空态

- 任务搜索与状态/项目筛选只在当前类型有任务，或用户已有筛选条件需要清除时显示；成功加载后真实零任务的空态不展示无效控件。
- 将刷新入口放入零任务空态，保持列表重新加载能力；当任务存在但筛选结果为空时保留筛选行和清除筛选操作。
- 布局预览不查询真实数据，不显示可用筛选或刷新操作；空态文案必须反映真实无记录状态。

## 2026-11-06 模板市场统一浏览区

- 用户选择统一浏览区，以“全部来源 / 本机内置 / 平台目录”切换模板来源；“全部模板 / 已收藏”独立于来源筛选。
- 平台断连时，默认全部来源仍显示并支持搜索本机模板；只在真实平台目录加载成功且有模板时显示数据版本/执行器筛选，并且只筛平台结果。
- 本机模板继续使用 Runtime 的真实工作流预览，保留本机项目目标选择和离线创建；平台目录未提供拓扑时不伪造节点图。
- 1280×720 桌面预览需检查合并列表内滚动、左栏平台状态、平台未连接引导和来源搜索；隔离预览中的“先创建本机项目”只代表空隔离 Runtime，不代表用户数据。

## 2026-11-06 质量报告空态

- 质量报告只有在收到服务端报告后才显示六项真实汇总指标；无结果时用一条状态和说明代替破折号指标占位。
- 桌面端无拆分结果时用普通说明文字，不保留独立虚线空框。真实报告分支仍保留原指标与数据拆分展示，后续需在连接服务的报告态复核。

## 2026-11-06 桌面断连空态与模板来源

- 用户确认质量报告无结果时收起六项摘要，显示紧凑的“尚未检查”状态；只有真实报告返回后才显示六项指标。
- 模板市场采用统一结果区，来源切换为“全部来源 / 本机内置 / 平台目录”；收藏筛选与来源筛选分开。本机模板由本机 Runtime 提供，可以脱离平台服务使用；平台目录单独依赖平台服务。
- 在断连文案中分清本机 Runtime 与平台服务，不能在 Runtime 不可用时显示本机模板“仍可离线使用”。
- 工作台“新建本机项目”按钮在 901px 及以上桌面宽度保持单行；该样式不扩展到手机端。

## 2026-11-06 模板市场双来源断连空态

- 统一模板浏览区的全来源空态应同时呈现本机 Runtime 与平台目录状态，不能让本机 Runtime 错误遮住平台来源状态。
- 本机来源独立浏览时，Runtime 未连接和目录为空都用完整空态结构说明当前状态与恢复路径；平台目录仍由平台服务状态和现有配置/重试入口引导。
- 搜索被禁用时，`title` 和 `aria-describedby` 应指向当前来源空态，不应把本机模板的禁用原因错误关联到平台服务状态。
- 全来源、本机和平台空态在桌面宽度下维持统一的目录标题与来源层级；模板卡片只由真实目录响应渲染。

## 2026-11-06 工作台最近运行摘要

- 工作台右侧辅助栏展示本机最近运行摘要；只从最近打开的本机工作流和本机 Runtime 的持久运行记录取真实状态、时间、项目与工作流名称。
- 每个工作流只汇总其最新运行；点击后打开对应工作流，编辑器按既有流程读取最新运行。当前运行列表按创建时间倒序。
- 本机项目目录是浏览器缓存时不展示过期运行状态。平台 API 的运行响应尚无工作流 ID，因此不能将平台运行摘要跳转到具体工作流；平台运行集成待接口补齐归属字段。
- 摘要样式仅适用于 901px 及以上桌面宽度；移动端暂缓。
