# React 主 UI

本目录是 ICT 模块化智能科研平台当前的 UI 开发主线，使用 React、TypeScript 与 Vite。产品导航、功能分区和服务状态以仓库内“开发统一方案 V4.0”为准；原 Tkinter 桌面端代码继续保留，不属于本目录。

## 本地运行

在本目录运行：

```powershell
npm install
npm run dev
```

`npm run dev` 先启动独立本机工作流运行时（默认 `127.0.0.1:8767`），再启动 Vite；已运行的本机 runtime 会复用，退出 Vite 时只关闭本脚本启动的 runtime。可通过 `ICT_LOCAL_RUNTIME_PORT` 覆盖端口。该服务不依赖平台 API，数据默认保存在 `%USERPROFILE%\.ict\runtime`。Vite 的 `/api` 请求仍代理到平台 API `http://127.0.0.1:8765`。开发构建与打包：

```powershell
npm run build
```

预览生产构建并同时启动本机工作流运行时：

```powershell
npm run build
npm run preview:local
```

预览默认使用 `127.0.0.1:4173`，可通过 `ICT_PREVIEW_PORT` 改端口；该方式仍要求本机 Python 环境和后端依赖已安装，不是独立安装包。

## 当前接入范围

- 工作台“项目”使用现有项目列表、详情和创建 API。
- 已返回的项目支持按名称、领域、角色或 ID 搜索，按真实研究领域筛选，并在卡片/表格视图间切换；8 个及以上默认表格。最近打开排序只保存最多 20 个实际打开项目 ID 于本浏览器，并且只重排当前 API 授权列表。当前 API 未提供最近活跃、项目目标或运行指标时不展示假数据。
- 在“个人信息与设置 → 服务配置”中输入 API 地址和服务令牌；令牌只保存在当前页面会话，不写入浏览器本地存储。
- 工作空间与团队服务尚未接入，因此顶部不提供切换入口；设置页保留服务状态说明。
- 待办 API 未接入时，不显示顶部待办入口、工作台待办卡或项目级待办摘要。
- 工作台最近工作流只记录本机打开过的项目工作流 ID 与时间；每次展示前通过当前可访问项目及其工作流 API 重新验证，不缓存名称或权限。论文复现任务工作流历史等待对应服务接入。
- 打开项目后，全局栏提供当前项目上下文选择器；仅在项目列表 API 返回多个可访问项目时允许切换。论文复现任务详情服务未接入，暂不显示复现任务切换器。
- 项目详情包含概览、工作流、资源和项目设置；设置页展示项目 API 返回的当前用户权限，成员名单与成员管理等待对应服务。项目工作流 API 支持项目范围列表/创建、草稿读取/保存、图与组件契约校验、不可变版本创建/浏览/恢复；恢复会新增草稿修订，不改写历史快照。编辑数据在运行前编译为独立 ICT `ExecutionPlan`，可按选定输出裁剪依赖图。本机 runtime 提供独立运行记录、节点状态和 ArtifactHandle；CSV 结构预检在本机运行，固定 Crossref DOI 节点可按用户确认读取公开书目信息。“产物”面板显示各自的有限摘要并明确标为“非科研结果”。
- 可从真实项目概览、已加载且无未保存修改的项目工作流，以及真实数据集详情打开 Agent 对话并暂存相应上下文；引用仅保留在页面状态中，可移除，Agent 服务接入前不会发送或保存。论文复现任务上下文需等待任务详情服务接入。
- 模板市场直接读取独立全局模板注册表（GET /api/v1/templates），不再遍历项目列表或依赖项目成员关系；当前后端只注册合成数据联调模板，不代表真实科研流程。选择项目/论文复现任务作为使用目标及创建模板副本的服务尚未接入。
- 论文复现/实验核验、Agent 对话与提案审批执行、账号设置服务尚未接入时显示明确状态，不填充固定演示项目、虚构任务或运行记录。
- 工作台项目与论文复现并列；运行信息属于具体工作流，不提供独立运行中心。

### 当前本机执行边界

- 项目与工作流列表的离线入口依赖本浏览器已有缓存；本机草稿、运行记录和 ArtifactHandle 存在本机 runtime。平台副本与本机副本分离，恢复平台连接后由用户手动同步。
- 本机 CSV 导入不上传平台；CSV 结构检查可在断开平台时运行。当前网络节点只允许固定 Crossref DOI 元数据端点，用户每次运行前确认，超时 20 秒、无自动重试；网络不可用时该节点失败并阻断依赖它的下游，独立本机分支仍可运行。平台云执行器尚未接入。
- 源码开发环境的 `npm run dev` 需要本机 Python 与后端依赖。Windows 便携 EXE 已包含 React 页面和本机 runtime，文件为 `desktop/dist/workflow-app/ICTWorkflowWorkbench.exe`；目前没有 Inno 安装器，Edge app 窗口的正式交互验收待完成。
- 本机 CSV 节点启用按输入内容 SHA-256、组件实现摘要/版本、参数、上游产物及 Python/平台环境生成的 Input Signature 缓存；命中仍会写入新的 Run/NodeRun 记录。资源准入采用保守的请求检查和并发上限，不是 OS 级硬隔离。

后端播种的项目可能包含合成数据。页面按 API 返回值展示，并遵守 research_ready 状态；合成数据不代表真实科研数据或科研结论。
