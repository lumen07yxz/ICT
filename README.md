## 当前演示基线

项目计划聚焦一个医学数据集、一项研究问题、一条固定科研模板、一项可核查论文主张对照，以及 AgentArts 的真实工具调用与人工审批闭环。详细范围和优先级以项目方案为准，比赛要求以官方规则和组委会通知为准。
